Politique de confidentialité

Cette page décrit quelles données Jeu du dico utilise pour fonctionner. L’app ne crée pas de compte chez l’éditeur. Le nom affiché est celui que vous tapez.

1. Sur votre iPhone

L’app peut enregistrer localement, uniquement pour le jeu :

  • votre prénom / pseudo tapé ;
  • un identifiant de siège (UUID) pour retrouver votre place après une microcoupure ;
  • un instantané de partie si vous êtes l’hôte.

Ces données restent sur l’appareil. Les supprimer : désinstaller l’app.

2. Parties en ligne (iCloud / CloudKit)

Pour créer ou rejoindre une room (code à 4 lettres), iCloud est requis. L’hôte publie l’état de la partie dans le container CloudKit iCloud.blomig.JeuDuDico (base publique Apple). Y figurent notamment :

  • le code de la room ;
  • les pseudos des joueurs présents ;
  • l’état de jeu (phase, scores, définitions ou propositions, votes).

Ces données servent uniquement à synchroniser la partie entre les iPhone de la room. Elles ne sont pas utilisées pour de la pub ni vendues. Apple traite CloudKit selon sa propre politique de confidentialité.

3. Même pièce (réseau local)

Un filet Bluetooth / Wi‑Fi local (Multipeer) peut relayer la même room en cas de microcoupure. Aucun serveur hors Apple n’est contacté pour cela.

4. Game Center

L’app peut tenter une connexion Game Center silencieuse au lancement (aucun écran de login n’est présenté par le jeu). Le nom Game Center n’est pas affiché. Les parties ne passent pas par les matchs Game Center.

5. Dictionnaire

Les mots et définitions sont embarqués dans l’app (Wiktionnaire, licence CC BY-SA 4.0). Aucune requête réseau n’est faite vers le Wiktionnaire pendant le jeu.

6. Publicité, analytique, enfants

Pas de SDK pub, pas d’outil d’analytique tiers, pas de tracking publicitaire (pas d’IDFA).

Pas de collecte volontaire de données d’enfants via un compte éditeur. iCloud / Game Center restent soumis aux règles et contrôles parentaux Apple.

7. Vos choix

  • Solo « Trouvez le mot » et partie démo : pas d’iCloud.
  • Refuser iCloud : vous ne pourrez pas créer ni rejoindre une room en ligne.
  • Supprimer l’app efface les données locales.

8. Modifications

La version à jour de cette politique est celle publiée sur cette page.

9. Contact

Pour une question de confidentialité, utilisez le formulaire de contact de la fiche App Store de Jeu du dico, ou le site www.blomig.com s’il est disponible.

Privacy Policy

Jeu du dico is an iPhone party game published by Terrasse Studio (Lomig Unger). There is no developer-run account. The name on screen is the nickname you type.

1. On your iPhone

The app may store locally, for gameplay only:

  • the nickname you typed;
  • a seat UUID so you can rejoin after a brief disconnect;
  • a host snapshot of the current game.

This stays on device. Uninstalling the app removes it.

2. Online games (iCloud / CloudKit)

Creating or joining a room (4-letter code) requires iCloud. The host publishes game state to Apple CloudKit (iCloud.blomig.JeuDuDico, public database), including room code, player nicknames, and game state (phase, scores, definitions or guesses, votes).

That data exists only to sync the table between phones in the room. It is not sold and not used for ads. Apple processes CloudKit under Apple’s privacy policy.

3. Same room (local network)

A Bluetooth / local Wi‑Fi fallback (Multipeer) may carry the same room across brief network drops. No third-party game server is involved.

4. Game Center

The app may attempt a silent Game Center sign-in at launch (the game never presents Apple’s login screen). The Game Center alias is not shown. Matches do not use Game Center matchmaking.

5. Dictionary

Words and definitions ship inside the app (Wiktionnaire, CC BY-SA 4.0). The game does not query Wiktionnaire over the network.

6. Ads, analytics, children

No third-party ad SDK, no third-party analytics, no IDFA.

The app does not run a developer account system aimed at collecting children’s data. iCloud / Game Center remain under Apple’s rules and parental controls.

7. Your choices

  • Solo “Find the word” and demo mode do not use iCloud.
  • Without iCloud you cannot create or join an online room.
  • Deleting the app deletes local data.

8. Changes

The current policy is the one published on this page.

9. Contact

For privacy questions, use the contact options on the Jeu du dico App Store listing, or www.blomig.com if available.
